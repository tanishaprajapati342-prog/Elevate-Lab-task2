# Superstore Retail Diagnostic Dashboard
A comprehensive Power BI diagnostic dashboard built to analyze retail superstore data, uncover regional sales trends, evaluate customer segments, and diagnose profit anomalies.
## Key Findings & Insights
- **High-Discount Anomaly:** The 'Phones' sub-category suffers from high discount rates leading to low or negative profit margins.
- **Top Revenue Drivers:** 'Copiers', 'Machines', and 'Accessories' act as key growth drivers for overall profitability.
- **Segment Performance:** The 'Consumer' segment and 'Standard Class' shipping mode dominate primary sales volumes.
- ## Dashboard Structure
- Matrix-focused layout with geographic and category-based drill-downs.
- Interactive filters for regions, segments, and ship modes.
